TokenForge — security token tooling

Issuance tooling for Indonesian real-world-asset issuers, with regulatory rules enforced at the token layer instead of in an off-chain database.

2026 Solana RWA SSTS · sRFC37

Issuance tooling for Indonesian real-world-asset issuers. It implements the Solana Security Token Standard (SSTS, the Halborn and Securitize design) with sRFC37-compliant transfer hooks, so a token can carry regulatory rules like transfer restrictions and holder eligibility at the token layer instead of in an off-chain database.

The repository is private while it is used with clients. The public product site shows what it does.

What it enforces

  • Transfer restrictions and holder eligibility encoded as token-level rules.
  • sRFC37-compliant transfer hooks so wallets and venues see the same enforcement path.
  • Issuance flows for real-world-asset issuers, not generic token deployment.
